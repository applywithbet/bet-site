# Dialog
A plain solid panel that asks one question.

- Product addition, built from the panel. Use the native `dialog` element with `.bet-dialog` and `showModal()`; the backdrop is a neutral dim.
- `.bet-dialog-body` (one-colour `.bet-dialog-title`, then plain lines) and `.bet-dialog-actions` (the dark pill for the answer, outline for "Cancel").
- No colour field, gradient, glow, kicker label or two-tone title in a dialog.
