# Table
A tracker table for wide screens: header labels in `muted`, rows split by faded `line`s, numbers in tabular figures, a `tint` row on hover.

- Product addition, built from the RowList and the faded divider.
- `.bet-table-wrap` (white, 24px radius, `hairline` ring, scrolls sideways when narrow) > `table.bet-table`.
- Status cells use chips; dates are short ("Nov 14"); one action per row at most, as a quiet button.
- On phones, switch to a RowList.
