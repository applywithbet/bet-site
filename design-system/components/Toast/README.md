# Toast
A short note after an action, with one way to take it back.

- Product addition, built from the glass capsule.
- `.bet-toast` is fixed at the bottom centre; add `.is-on` to show it (it rises 16px, 0.45s). A `.bet-btn-quiet` action in `primary` ("Undo").
- One line that says what happened: "Marked as applied", "Moved to Not interested". Hide it after 5s, or when the person acts.
