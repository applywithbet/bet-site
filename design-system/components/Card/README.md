# Card
A large solid panel standing on the page: a posting, a profile, a settings page. Details on the left, content on the right.

- `.bet-card`: `surface`, 24px radius (20px on phones), the masked `tile-line` edge, `shadow-raised`.
- A details column uses `.bet-dl` (label over value, faded lines between).
- Long text inside: 1.02rem at line-height 1.68 in ink at 88%, at most `measure` (62ch). Section titles use `.bet-title`.
- No gradients, glows or tinted fills in a card. The page around it is `bg`.
