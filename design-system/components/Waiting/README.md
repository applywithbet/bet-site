# Waiting
Three quiet ways to wait: wait dots, a spinner inside a busy button, and a progress line.

- `.bet-wait`: three dots in a small glass capsule. Show it only after 600ms of waiting.
- `.bet-spin` (18px) only inside a button that is busy.
- `.bet-progress` with `--p` from 0 to 1: a 4px `primary` line on a `hairline` track, for "3 of 20 applied".
- Never a full-screen spinner or a play button over media.
