# Chip
Small labels: status chips, outlined tags, glass feature pills and the pinging "new" dot.

- Status: `.bet-chip` (12px, 500, 4px 10px). `-green` Interview / Filled, `-blue` Applied / New grad, `-purple` for things Bet did (Drafted by Bet, Viewed), `-amber` needs a look, `-red` closed or failed, plain (`tint`, `muted`) for neutral states. A chip always carries a word; colour is never the only signal.
- `.bet-tag`: outlined (1.5px `tile-line`) for skills and facts on a card.
- `.bet-pill`: the glass feature pill with a 14px tile icon (`.bet-pi.bet-pi-sm`); its icon redraws on hover.
- `.bet-new`: blue text with a 6px dot that pings, for the newest item only.
- Don't stack chips for decoration. One or two per row, saying something true.
